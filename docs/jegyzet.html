Kódolási séma: javítás/jelzés + vektorok (4–8. feladat)

A 4–8. feladat ugyanarra a kódolási sémára épül (az ábrán egy kódoló táblázat, egy modulo-2 összeadó a hibavektorral, majd egy \(c': \min d(c,v)\) dekódoló blokk). A kódszótáblázat (az ábráról):

00 → 00000 01 → 01010 10 → 10101 11 → 11111

Ez egy \(C(5,2)\) kód (4 kódszó, hossz 5). A kódszavak páronkénti Hamming-távolsága: \(d_{min} = 2\).

4. feladat (5p) — Hány hibát tud JAVÍTANI a kód?

Helyes válasz: 0 — Javítóképesség: \(t = \lfloor(d_{min}-1)/2\rfloor = \lfloor(2-1)/2\rfloor = \lfloor0{,}5\rfloor = 0\). A \(d_{min} = 2\) kóddal egy hibát sem lehet biztosan javítani.

5. feladat (5p) — Hány hibát JELEZ a kód?

Helyes válasz: 1 — Jelzőképesség (detektálás): \(s = d_{min} - 1 = 2 - 1 = 1\). A kód 1 hibát képes detektálni (de nem javítani).

6. feladat (3p) — Add meg a \(v\) vektort!

Helyes válasz: (00001) — \(v\) az ábra szerinti hibavektor (a csatornán hozzáadott hiba). Egyetlen hibabit az 5. pozíción: \(00001\).

7. feladat (3p) — Add meg a \(c'\) vektort!

Helyes válasz: (00000) — \(c'\) a dekódolt kódszó (a \(\min d(c,v)\) legközelebbi kódszó szabály eredménye). A vett szóhoz legközelebbi érvényes kódszó a \(00000\).

8. feladat (4p) — Add meg a \(u'\) vektort!

Helyes válasz: (00) — \(u'\) a dekódolt üzenet: a \(c' = 00000\) kódszóhoz tartozó 2 bites üzenet a táblázat szerint \(00\).

Hibacsoportok, szindróma, kódparaméterek (9–12. feladat)

9. feladat (6p) — Hány hibavektor van egy hibacsoportban?

Feladat: Hány darab hibavektor szerepel egy \(C(9,3)\) lineáris bináris kód egyes hibacsoportjaiban?

Helyes válasz: 8 — Egy hibacsoport (coset) mérete = kódszavak száma = \(2^k = 2^3 = 8\). (A szindrómák száma \(2^{\,n-k} = 2^6 = 64\), és \(64 \cdot 8 = 512 = 2^9\) az összes vektor.)

10. feladat (7p) — Kódparaméterek a hibacsoportból

Feladat: Egy bináris lineáris kódnak egy adott szindrómavektorhoz tartozó hibacsoportjában 32 db \(l\) dimenziós hibavektor van. Add meg a kód paramétereit! (Formátum: \(n,k\))

Helyes válasz: (7,5) — A hibacsoport mérete \(2^k = 32 \Rightarrow k = 5\). A hibavektorok dimenziója \(l = n\); a megadott adatokból \(n = 7\) (így \(2^{7-5}=4\) szindróma és \(4\cdot32 = 128 = 2^7\)).

11. feladat (7p) — RS-kód paraméterei adott javítóképességre

Feladat: A \(GF(17)\) feletti minden 5 hibát javító RS kódot implementálunk. Add meg a kód paramétereit!

Helyes válasz: (16,6) — RS-kód hossza: \(n = q - 1 = 17 - 1 = 16\). Javítóképesség: \(t = \lfloor(n-k)/2\rfloor = 5 \Rightarrow n - k = 2t = 10 \Rightarrow k = 16 - 10 = 6\). Tehát \(C(16,6)\).

12. feladat (4p) — Kódparaméterek a hibacsoportból (bináris)

Feladat: Adott egy bináris lineáris kód, amelynek hibacsoportja:
\(E_{(011)} = \{ e : H\cdot e^{T} = s^{T} \} = \{(010000),(011111),(000011),(001100),(110110),(111001),(100101),(101010)\}\). Add meg a kód paramétereit!

Helyes válasz: (6,3) — A hibavektorok hossza \(6 \Rightarrow n = 6\). A hibacsoportban \(8 = 2^k\) vektor van \(\Rightarrow k = 3\). Tehát \(C(6,3)\).

1. feladat (5p) — \(e_1 = 100001\) szindrómája

Helyes válasz: (1100) — \(s = H\cdot e_1^{T}\). A hibavektor az 1. és 6. pozíción tartalmaz 1-est → a \(H\) 1. és 6. oszlopának összege (mod 2). Az 1. oszlop \(P^{T}\) 1. oszlopa = \((1,1,0,1)\), a 6. oszlop az \(I_4\) utolsó egységoszlopa = \((0,0,0,1)\). Összeg: \((1,1,0,0)\) = \(1100\). ✓

2. feladat (2p) — \(e_2 = 110000\) szindrómája

Helyes válasz: (0010) — \(H\) 1. + 2. oszlopa. \(P^{T}\) 1. oszlopa \((1,1,0,1)\), 2. oszlopa \((1,1,1,1)\). Összeg: \((0,0,1,0)\) = \(0010\). ✓

3. feladat (5p) — Egy hibacsoportba tartozik-e \(e_1\) és \(e_2\)?

Helyes válasz: Hamis (False) — Két hibavektor pontosan akkor van azonos hibacsoportban (coset), ha azonos a szindrómájuk. Itt \(1100 \ne 0010\), tehát különböző cosetben vannak → Hamis.

4. feladat (10p) — \(v = 011110\) → detektált kódszó

Az RS-kód generátorpolinomja \(g(x) = (x-\alpha^1)(x-\alpha^2)\cdots(x-\alpha^{2t})\), ahol \(t\) a hibajavító képesség. Kétszeres hibajavítónál \(2t = 4\) gyök. A főegyüttható mindig 1. A trükk a gyöktényezők páronkénti összeszorzása, mindig az adott testben.

A) RS GF(7), \(\alpha = 5\), kétszeres hibajavító (5.ZH/7.)

Gyökök: \(\alpha=5,\ \alpha^2=25\bmod7=4,\ \alpha^3=5\cdot4=20\bmod7=6,\ \alpha^4=5\cdot6=30\bmod7=2\). Tehát \(g(x) = (x-5)(x-4)(x-6)(x-2)\) GF(7) felett.

1. lépés — \((x-5)(x-4)\): \(= x^2 - (5+4)x + 5\cdot4 = x^2 - 9x + 20\). Mod 7: \(-9 \equiv 5\), \(20 \equiv 6\). → \(x^2 + 5x + 6\).

2. lépés — \((x-6)(x-2)\): \(= x^2 - (6+2)x + 6\cdot2 = x^2 - 8x + 12\). Mod 7: \(-8 \equiv 6\), \(12 \equiv 5\). → \(x^2 + 6x + 5\).

3. lépés — a két másodfokú szorzata \((x^2+5x+6)(x^2+6x+5)\) mod 7:

\(x^2\)\(6x\)\(5\)
\(x^2\)\(x^4\)\(6x^3\)\(5x^2\)
\(5x\)\(5x^3\)\(30x^2\)\(25x\)
\(6\)\(6x^2\)\(36x\)\(30\)

Összegyűjtve (mod 7): \(x^4\): 1; \(x^3\): \(6+5=11\equiv4\); \(x^2\): \(5+30+6=41\equiv6\); \(x^1\): \(25+36=61\equiv5\); \(x^0\): \(30\equiv2\).

$$ g(x) = x^4 + 4x^3 + 6x^2 + 5x + 2 $$

Együtthatók (a legnagyobb hatványtól): \(1,4,6,5,2\) ✅. Ellenőrzés: \(g(5) \bmod 7 = 0\) ✓ (gyök).

B) RS GF(8), kétszeres hibajavító, standard alak (5.ZH/6.)

GF(8)-ban a primitív polinom \(x^3 + x + 1\), azaz \(y^3 = y + 1\). A hatványtábla (elem ↔ y-kitevő):

Kulcs: GF(8)-ban az összeadás = XOR (bitenkénti), a szorzás = y-kitevők összege mod 7. És mivel karakterisztika 2: \(-r = r\), tehát \((x-\alpha^i) = (x+\alpha^i)\).

Gyökök: \(y^1, y^2, y^3, y^4\). Így \(g(x) = (x+y)(x+y^2)(x+y^3)(x+y^4)\).

1. lépés — \((x+y)(x+y^2)\): \(= x^2 + (y+y^2)x + y\cdot y^2 = x^2 + (y+y^2)x + y^3\). \(y+y^2 = 010 \oplus 100 = 110 = y^4\). → \(x^2 + y^4 x + y^3\).

2. lépés — \((x+y^3)(x+y^4)\): \(= x^2 + (y^3+y^4)x + y^7\). \(y^3+y^4 = 011 \oplus 110 = 101 = y^6\). \(y^7 = 1\). → \(x^2 + y^6 x + 1\).

3. lépés — \((x^2 + y^4 x + y^3)(x^2 + y^6 x + 1)\):

  • \(x^4\): 1
  • \(x^3\): \(y^6 + y^4 = 101 \oplus 110 = 011 = y^3\)

  • \(x^1\): \(y^4\cdot1 + y^3\cdot y^6 = y^4 + y^9 = y^4 + y^2 = 110 \oplus 100 = 010 = y^1\)
  • \(x^0\): \(y^3\cdot1 = y^3\)
$$ g(x) = x^4 + y^3 x^3 + y^0 x^2 + y^1 x + y^3 $$

Együtthatók standard alakban (y-kitevők, a legnagyobb hatványtól): \(0,3,0,1,3\) ✅.

Gyakori buktatók (a ZH-kban elrontott feladatok tanulságai)

  • Jelzés ≠ javítás. Hamming: jelez 2-t, javít 1-et (\(t = \lfloor(d-1)/2\rfloor\)).
  • „Legnagyobb súlyú kódszó" vs. „coset elem". Kódszónál a 0-szindrómás halmazból (\(u\cdot G\)); cosetnél \(e \oplus c_i\).
  • \(H \ne G^{T}\). Szisztematikusan \(G=[I\mid P]\) → \(H=[P^{T}\mid I]\). A \(P\)-t transzponálni kell!
  • Előre- vs. visszacsatolt regiszter. Előre = szorzás/kódolás, vissza = osztás/dekódolás.
  • RS kódolás GF(q)-ben. Az \(u=(2,2) → (4,5,3,0,6,1)\) számítást gyakorold be.
  • Viète-előjel és mod. \(b = -(\alpha+\alpha^2)\), a mínuszt a test szerint vidd vissza.
  • Singleton felső korlát. \(d_{min} \le n-k+1\).
  • Szindrómatáblázat sorai: \(2^{\,n-k}\) (nem \(2^n\)).
  • GF(2^m) szorzás = kitevők összege mod \((2^m-1)\). \(4\times5\) GF(8)-ban: \(y^9=y^2 → 2\).
  • Shiftregiszter méretezése. Kódoló: késleltetők = \(\deg g\), szorzók = \(\deg g + 1\).
  • Entrópia ≠ \(2^N\). Egyenletes N-szimbólumú forrás: \(H = \log_2 N\).
